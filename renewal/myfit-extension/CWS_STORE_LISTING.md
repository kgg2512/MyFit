```
MyFit — 사이즈 핏 확인

쇼핑몰에서 옷을 사다가 "이게 내 몸에 맞을까?" 고민한 적 있으신가요?
MyFit은 그 순간을 해결합니다.

────────────────────────

어떻게 작동하나요?

1. 무신사, Nike, Zara, Uniqlo, H&M 등 지원 쇼핑몰 방문
2. 상품 페이지에서 MyFit 아이콘 클릭 → 사이드 패널 열림
3. 내 신체 치수 입력 (키, 몸무게, 가슴·허리·엉덩이)
4. 3D 체형 모델 + 2D 핏 분석으로 어깨·가슴·허리 부위별 핏 확인
5. 결과 확인 후 구매 결정

────────────────────────

주요 기능

• 3D 체형 모델 — 내 치수로 생성되는 개인화 3D 모델
• 2D 핏 분석 — 브랜드 사이즈표 × 내 치수 → 부위별 핏(타이트/적정/오버)
• 멀티 쇼핑몰 지원 — 무신사, Nike, Zara, Uniqlo, H&M
• 사이드 패널 — 쇼핑 페이지를 떠나지 않고 확인
• 치수 저장 — 한 번 입력하면 모든 쇼핑몰에서 자동 사용

────────────────────────

개인정보 보호

• 신체 측정치는 본인 기기에만 저장됩니다
• 사진을 수집하거나 외부 서버로 전송하지 않습니다
• 어떠한 개인정보도 판매하지 않습니다

────────────────────────

지원 쇼핑몰

무신사 / Nike / Zara / Uniqlo / H&M
(추후 지원 쇼핑몰 지속 확대 예정)

────────────────────────

MyFit은 사이즈 고민을 브라우저 안에서 끝냅니다.
반품 걱정 없이, 자신 있게 구매하세요.
```

```
• Saved Measurements — Enter once, use everywhere
```
