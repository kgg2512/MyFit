기술 한계 안내 (CTO 정직 보고)
1. 앞면 전용: 2D 사진은 정면만 캡처됨. 측면·뒤 체형은 추정 불가 — 허리·엉덩이 입력값으로 보완.
2. 원단 미반영: 신축성(면/폴리/울) 차이가 최대 ±4cm 오차를 만듦 — 치수 차이만으로 판단 시 한계.
3. 포즈 보정 없음: 다리 벌림·팔 각도 등 포즈에 따라 픽셀→cm 변환 오차 발생.
4. MediaPipe CSP 이슈: Chrome Extension MV3 환경에서 MediaPipe WASM은 wasm-unsafe-eval로 로드 가능하나, CDN 스크립트 주입 불가. 로컬 번들(약 8-12MB) 필요 — 현재 프로토타입은 수동 입력값 기반으로 대체.
