# TrueToForm 소비자 관점 벤치마킹 → MyFit 적용 (2026-06-30)

> 회장 지시: "트루투폼을 소비자 관점에서 다시 상세히 살펴보고, 구매로 이어지는 여정을 분석 → MyFit 홈페이지/앱/크롬확장의 디자인·구성·결제방식·구동방식·메뉴위치를 벤치마킹하라." MyFit = TrueToForm의 B2C판.
> **스크랩 범위:** truetoform.fit 홈(md+스크린샷)·/pricing·케이스스터디 4건·web.truetoform.fit·widget.truetoform.fit 실스크랩(firecrawl 14콜). [확인]=이번 스크랩 직접근거. web/widget 내부플로우는 브라우저·임베드 게이트로 직접캡처 불가→케이스스터디 기반 [추정] 보강.

## 1. TrueToForm 개요
- **무엇을 파는가 [확인]:** 의류 브랜드(B2B)에 파는 "3D 신체측정 + 핏 예측" SW. 운영사 Tam Technologies.
- **두 제품라인 [확인]:** ①기성복=**핏예측 위젯**(상품 상세페이지 사이즈셀렉터 옆 임베드) ②맞춤복=**스캔앱+측정 대시보드**.
- **구조 [확인]:** 본질 B2B(브랜드에 판매)이나 **쇼퍼(소비자)가 위젯/스캔을 직접 조작**하는 B2B2C. MyFit "B2C판"=이 쇼퍼 레이어를 **브랜드 의존 없이 소비자에게 직접** 제공.
- **가치제안 [확인]:** "The right fit, the first time" — 정적 사이즈표를 개인화 핏예측으로 대체(97% 정확도).

## 2. 소비자 구매 여정 (1인칭)
> TTF는 자사 홈에서 구매를 일으키지 않고 **브랜드 상품페이지에 기생(embed)**. 가장 중요한 구조적 사실.

| 단계 | 화면·문구 | 마찰 | 전환장치 |
|---|---|---|---|
| ①진입/발견 | 사이즈 셀렉터 **바로 옆** 위젯, 페이지 이동 없음 [추정] | 위젯 인지 실패 가능 | 사이즈 고민 **그 지점·그 순간** 노출(컨텍스트 일치) |
| ②가치이해 | 단일추천 아닌 **시각적 답** 약속 [확인] | "또 측정?" 거부감 | **두 갈래**: (a)측정값 입력(빠름) (b)QR 폰스캔(정확), 앱설치 없음 [확인] |
| ③측정/스캔 | 입력 or QR→폰브라우저 스캔(몇분), **사진·영상 비저장** [확인] | 시간·프라이버시 불안 | "no app, no stored photos" 문구로 불안차단 [확인] |
| ④핏확인(핵심) | 3D모델→**부위별(가슴·허리·엉덩이)+밑단** 피드백, **사이즈 토글 비교** [확인] | 블랙박스 불신 | best-size 하나가 아니라 **모든 사이즈가 내 몸에 어떻게 다른지 시각화**+취향선택 [확인] |
| ⑤구매/CTA | 사이즈 확정→**브랜드 장바구니로 직결**(이탈0) | — | 결제를 만들지 않고 **브랜드 흐름에 핏 확신만 주입**→담기 3.5배·전환 4.2배(Jordan Craig) [확인] |

**핵심 통찰 [확인+추정]:** TTF의 천재성=**별도 목적지를 안 만든 것.** 망설임이 생기는 정확한 순간·위치에 답이 끼어든다(마찰0·이탈0). **MyFit이 독립 앱/웹으로만 가면 이 무마찰 진입을 잃는다 → 크롬확장이 MyFit의 전략적 핵심.**

## 3. 디자인 언어 [확인]
- **색(theme #000000):** 모노크롬(흑백+뉴트럴 오프화이트 카드), 강조색 최소, 럭셔리·테크 신뢰톤.
- **타이포:** 큰 헤드라인 + **마지막 구절만 이탤릭** 강조("the first time."), 본문 산세리프.
- **레이아웃:** Webflow 풀블리드 섹션 스택(히어로→Trusted by 로고→통계 원형아이콘→위젯데모→테스티모니얼→프레스→투자사→연락폼).
- **신뢰요소 과다 [확인]:** 고객로고·"As seen in"·교육파트너(FIT/Parsons/RISD)·투자사·어드바이저(Nigel Barker). **B2B 신뢰구축이 디자인의 절반.**
- **통계 배지:** 원형아이콘+굵은숫자(97% 정확·43% 반품↓·60+ 측정).

## 4. 메뉴 구조(IA) [확인]
- 상단: 로고 / **Solutions 드롭다운**(Made-to-Measure: Widget·Scan App·Dashboard·Exports / Ready-to-Wear: Fit Prediction Widget) / Pricing / API / Contact / Log In / **Start For Free**(강조) / Book a demo(Calendly).
- **통찰:** ①두 사용자(기성복vs맞춤복)를 메뉴 최상위서 분기 ②CTA 이원화(셀프서브 $40 vs 영업 문의형) ③푸터=Press·Testimonials·Help·Careers·법무·뉴스레터.

## 5. 작동방식(기술 UX) [확인]
- **측정 두 갈래:** ①빠른입력(키·몸무게) ②QR→폰브라우저 스캔(앱설치 불필요, 사진 비저장, 60+측정·97%정확, IRB 300+명 검증).
- **"설문 vs 스캔" 인포그래픽**으로 정밀도-노력 트레이드오프 **선택권** 제공.
- **핏결과:** 3D 아바타 위 부위별(타이트/맞음/여유)+밑단 위치, **S/M/L 토글 비교**로 블랙박스 불신 격파. 맞춤복은 60+측정 CSV/OBJ 내보내기.

## 7. → MyFit 벤치마킹 매핑 (가장 중요)
> MyFit 차별점=**쇼핑몰 사이즈표 자동추출×내 치수→부위별 핏.** TTF는 브랜드가 핏데이터 제공해야 작동(B2B 설치장벽). **MyFit은 브랜드 협조 없이 공개 사이즈표를 긁어 소비자가 직접 핏을 본다=TTF 최대약점(설치장벽) 우회.** 이게 "B2C판"의 진짜 의미.

| TTF 요소 | MyFit 웹 | MyFit 앱 | MyFit 크롬확장 |
|---|---|---|---|
| 무마찰 진입(상품페이지 옆 위젯) | 프로필·핏기록 허브 | 측정/스캔 홈+재방문 푸시 | **★최우선: 쇼핑몰 상품페이지에 핏 오버레이 자동주입**(TTF는 브랜드설치 필요, MyFit은 소비자가 확장만 깔면 모든몰에서) |
| 두 갈래 입력 | 측정값 입력폼 | 폰카메라 스캔 | 저장된 내 치수 자동적용 |
| 부위별 핏+밑단 | 핏결과 상세(컬러바) | 동일+저장·공유 | 상품페이지 위 **미니 핏배지**("허리 타이트, 기장+3cm") |
| 사이즈 토글 비교 | S/M/L 토글 | 동일 | 팝오버 토글 |
| best-size 블랙박스 격파 | 부위별 시각+추천 동시 | 동일 | 셀렉터 옆 "당신껜 M ✓" |
| 사이즈표 데이터 | (TTF=브랜드 제공) → **MyFit=쇼핑몰표 자동파싱** | 동일 엔진 | **확장이 현재 페이지 사이즈표 DOM 직접추출=MyFit 고유무기** |
| 프라이버시 | "측정값만, 사진 비저장" | 온디바이스 | "데이터 브라우저 로컬" |
| 무료진입 | 무료 핏체크 N회 | 무료 스캔 N회 | 확장 무료 |
| 신뢰 시각요소 | "97% 정확" 배지+후기 | 앱평점 | 스토어 리뷰·설치수 |
| 결제모델 | (TTF=브랜드종량) → **MyFit=소비자 프리미엄 or 제휴커미션 재설계** | 인앱구독 | 확장 미끼(무료)→웹/앱 전환 |

**핵심:** **크롬확장 = MyFit의 "위젯"이자 TTF 대비 결정적 우위.** TTF 위젯은 브랜드가 심어야 1개 사이트에서만. MyFit 확장은 소비자 1명 설치→무신사·쿠팡·자라 등 **모든 사이트 사이즈표 자동추출**→공급측 영업 없이 수요측부터 성장. 웹/앱=**내 치수 금고+핏 히스토리**(확장의 백엔드).

## 8. 즉시 실행 Top 10 (우선순위순)
1. **크롬확장을 "상품페이지 인라인 핏배지"로 재정의** — TTF 무마찰 진입을 브랜드설치 없이 소비자측 작동(MyFit 최대무기). [확인]
2. **두 갈래 진입 UX**(빠른입력 vs 정밀스캔) 모든 플랫폼 첫화면. [확인]
3. **핏결과=단일추천이 아닌 부위별 시각+사이즈 토글 비교**(가슴·허리·엉덩이·기장 컬러). [확인]
4. **프라이버시 카피 전면**: "사진·영상 저장안함, 측정값만". [확인]
5. **무과금 진입**: "무료 핏체크 N회, 카드불필요". [확인]
6. **측정값 계정저장→전 카탈로그 재사용**(Fit Calculator, Dessy 패턴). [확인]
7. **정량 신뢰배지**(정확%·측정부위수·반품↓%) 원형아이콘. [확인]
8. **모노크롬+헤드라인 끝구절 이탤릭** 디자인 시스템. [확인]
9. **메뉴 IA=소비자 단일동선**("측정→핏보기→쇼핑") — TTF의 복잡한 Solutions 드롭다운은 반면교사(B2B라 필요했을 뿐). [역설계]
10. **B2C 수익모델 재설계**(확장 무료미끼→소비자 프리미엄 or 쇼핑몰 제휴커미션) — "소비자가 내나/브랜드가 내나"를 출시 전 확정해야 UX·CTA 정렬. [TTF 한계서 도출]

## 미해결·리스크
- web/widget 내부 UI는 게이트로 직접캡처 불가 → 스캔/위젯 단계는 [추정]. 정밀히 보려면 실제 브랜드 상품페이지(jordancraig.com 등)에서 Playwright로 위젯 직접조작 캡처 권장.
- **MyFit "공개 사이즈표 자동추출"의 합법성**(스크래핑 ToS·DOM 다양성)은 별도 검증 필요 → §1.5 CLO(저작권·약관) 검토 대상.
