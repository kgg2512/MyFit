## 핵심 기능

- 쇼핑몰 자동 감지 (무신사·Nike·Zara·Uniqlo·H&M)
- AI 사이즈 추천 + 핏 점수
- FASHN AI 실제 착용 이미지 생성
- 3D 아바타 가상 피팅

## 기술 스택

- **Extension**: Chrome MV3, JavaScript
- **AI**: FASHN AI API
- **인프라**: Cloudflare Workers
- **3D**: Three.js
